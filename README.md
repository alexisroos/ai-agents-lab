# ai-agents-lab

Monorepo of local agent assistants maintained by Alexis Roos.

This repository contains small agent projects designed to run locally on macOS with OpenClaw-based tooling.

Projects:

- `twitter_assistant/` — Browse Twitter, score and aggregate daily digests.
- `audio_assistant/` — Real-time speech transcription assistant with ChatGPT integration.

Author: Alexis Roos

License: MIT — see `LICENSE` for full text.

Quick start:

```bash
cd ai-agents-lab
# per-project instructions live in each project's README/REQUIREMENTS
```
